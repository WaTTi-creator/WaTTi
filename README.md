# WaTTi — Personal Universe

This repository is the GitHub home for the WaTTi Personal Universe project.

## Role

GitHub is the durable source-control and backup layer for the project. Lovable may be used as a visual/full-stack builder, while GitHub preserves source code, history, branches, and recoverability.

## Current state

- Repository: `WaTTi-creator/WaTTi`
- Default branch: `main`
- The repository started empty and is being prepared for integration with the existing Lovable project **Dark Cinema Showcase**.
- No application source code has been imported yet.

## Integration principle

Do not rebuild or overwrite the existing Lovable application blindly. First establish a safe synchronization path, preserve the current working version, and use commits/branches as checkpoints.

## Planned structure

- `main` — stable project state
- Feature branches — isolated changes before merging
- `docs/` — architecture and project decisions
- Application source — to be imported from the existing Lovable project once the connection/workflow is verified

## Design direction

The Personal Universe is a long-term digital home for original creative work, media, writing, archives, and related worlds. Dark Media Gallery is the first world/section within that larger universe.
